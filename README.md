# Adalomoon Dialogue

Dalamud-плагин для атмосферного отображения текста открытого диалога в Final Fantasy XIV.

## Реализовано

- Наблюдение за `Talk`, `BattleTalk`, `TalkSubtitle` и `MiniTalk` через `IAddonLifecycle`.
- Чтение уже отображаемых текстовых узлов диалога и показ их в синей панели с золотой рамкой и пергаментной областью справа.
- При начале обычного диалога (`Talk`) — один раз плавно приближает камеру до текущего минимального игрового расстояния и поворачивает её примерно на 27° вправо. После кадрирования плагин перестаёт менять камеру, чтобы игрок мог свободно вращать её и менять зум.
- Для обычного окна `Talk` скрывает штатное окно, сохраняя активный игровой диалог и его управление. Видимость восстанавливается при закрытии диалога и выгрузке плагина.
- Компактная панель использует отдельный шрифт Dalamud 22 px с поддержкой игровых языков, отображает имя NPC целиком или с аккуратным сокращением, автоматически ограничивает высоту текста прокруткой и предоставляет рабочую кнопку закрытия.
- Escape отслеживается независимо от фокуса окна, поэтому закрывает разговор, даже если игровой текст временно скрыт.
- Панель закрывается вместе с игровым диалогом.
- Игровой текст и варианты ответа не изменяются; игрок выбирает их штатными средствами.
- Файлы игры и ввод игрока не затрагиваются. Для кадрирования используется структура обычной камеры из FFXIVClientStructs; значения зума остаются внутри заданных клиентом границ.

Панель скрывает визуальную часть обычного окна `Talk`, а подтверждение продолжает обрабатываться игрой. Escape закрывает разговор через штатное закрытие игрового окна. Другие типы диалоговых окон отображаются поверх без изменения их видимости. Текст берётся из уже существующих текстовых узлов интерфейса. Камера меняется только для стандартной игровой камеры, если игрок не находится от первого лица; угол задаётся относительно текущего ракурса и не отслеживает положение NPC.

## Сборка

Требуется установленный .NET 10 SDK, текущий Dalamud.NET.Sdk 15 и доступ к пакетам Dalamud. Из каталога проекта:

```powershell
dotnet build .\Adalomoon.csproj -c Release
```

Результат будет размещён в `bin\Release\Adalomoon.dll` и `Adalomoon.json`.

## Установка из custom repository

В Dalamud → Settings → Experimental → Custom Plugin Repositories добавьте URL:

```text
https://raw.githubusercontent.com/onisnakefang-max/Adalomoon-Dialogue/main/pluginmaster.json
```

Затем сохраните настройки и найдите **Adalomoon Dialogue** в установщике плагинов. Репозиторий и релизы публичные. Пакет появится после успешной GitHub Actions сборки.

## Установка для локальной разработки

1. Соберите проект в Release.
2. В XIVLauncher откройте `/xlsettings` → Experimental и добавьте полный путь к `Adalomoon.dll` в Dev Plugin Locations.
3. Откройте `/xlplugins` → Dev Tools → Installed Dev Plugins и включите Adalomoon Dialogue.
4. Для проверки начните разговор с NPC. Плагин покажет панель автоматически; варианты выбираются в стандартном игровом окне.

Чтобы использовать плагин, Dalamud/XIVLauncher должны быть установлены и включены. Сторонние плагины не являются официально поддерживаемой Square Enix функцией.

## Исходники и лицензии ориентиров

Код проекта написан отдельно. Для компоновки панели использован общий визуальный ориентир из MIT-проекта [DialogUI-WotLK](https://github.com/ghbset/DialogUI-WotLK); исходники и графика оттуда не включены. [Echoglossian](https://github.com/lokinmodar/Echoglossian) полезен как технический пример существующих диалоговых поверхностей, однако его лицензия ограничивает перераспространение/производные работы; код из него не копировался.

## Известные границы

- Нужна проверка в живом клиенте: после обновления стоит убедиться, что штатное окно скрывается и снова показывается при закрытии, а подтверждение продолжает работать.
- Управление камерой зависит от внутренней структуры клиента. Плагин не патчит код клиента, не снимает ограничения зума и перестаёт управлять камерой сразу после короткого перехода.
- Для официального репозитория Dalamud требуется собственная проверка правил публикации и раскрытие использования ИИ.
